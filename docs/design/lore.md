# 模组叙事与内容逻辑

> 目的：让每件内容都能回答“它为什么在这个世界里”“玩家为什么要它”。新增内容先对照本文件。

## 世界观

1. **尖塔苏醒**。海上的尖塔岛屿上，活着的高塔“尖塔”苏醒了。它的力量像根系一样渗入大地，在世界各处留下了**尖塔的痕迹**：新的矿物、被同化的生物群系（密林、暗港、巢穴），以及攀登者留下的建筑。
2. **先古之民**。尼奥（Neow）等先古之民比尖塔更古老。他们的馈赠（熔岩石等）稀有而强大，通常与 Boss 和“额外的奖赏”有关。
3. **攀登者**。五位攀登者（铁甲战士、静默猎手、储君、亡灵契约师、故障机器人）曾来到这片大陆。他们的遗迹（角色建筑）里能找到与其相关的材料和遗物，例如铁甲战士的**硫磺**、储君的**星系尘埃**（群星）。
4. **荣耀**。原版模式中，“荣耀”是矗立在大陆上的**高塔建筑群**，是原版模式的终局挑战；爬塔模式中则是最终层。

## 核心循环（原版模式）

```
采集尖塔材料 ──► 制作装备 / 一次性消耗品（“体验”遗物效果）
      │                         │
      ▼                         ▼
探索尖塔群系与建筑 ◄──── 用材料 + 战利品合成永久遗物（阶段 5）
      │
      ▼
挑战尖塔 Boss ──► 荣耀高塔（终局）
```

## 材料的三段式

每种源自 STS2 遗物的材料都按这条线设计，保证“遗物”在 Minecraft 里有来历：

| 段 | 含义 | 例：钨合金 |
|---|---|---|
| ① 材料 | 从世界中获得，可参与原版和模组配方 | 黑钨矿石 → 钨锭 → 钨合金锭（与铁、铜、煤合金化） |
| ② 装备 / 消耗品 | 一次性或部分体现遗物效果 | 钨合金盔甲：每件少受 0.25 伤害 |
| ③ 遗物（阶段 5） | 永久、完整的遗物效果，需要稀有战利品 | 钨合金棍：每次失去生命少失去 1 点 |

## 与原版的关系

- 原版材料是基础：模组配方大量使用铁、铜、煤、骨粉、岩浆块等。
- 模组材料回馈原版：硫磺可做火药；熔岩石能让原版 Boss（凋灵、末影龙等）掉落双倍。
- 原版 Boss 与模组 Boss 一视同仁（灾厄可处决 Boss，熔岩石对 Boss 生效）。
