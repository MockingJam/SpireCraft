# 群系（阶段 7）

依据 STS2 背景画（wiki: StS2_Overgrowth / Underdocks / Hive / Glory.png）设计。背景原画整体很暗，取其**色相与母题**，亮度按原版方块的亮度区间重新定（与阶段 2 的“取样原版调色板”原则一致）。

## 一、背景画要点

| 层 | 原画观感 | 可转成方块/地物的母题 |
|---|---|---|
| 密林 Overgrowth（第一幕） | 深绿森林里的**苔绿色巨石遗迹**（方块状砌石、倒塌的柱子），石柱上缠着**带黄绿色光点的藤蔓**；草地上散落**石板铺路**；前景是蕨类 | 苔绿遗迹石砖、裂纹/雕刻变体；萤光藤；石板路；蕨丛；蘑菇怪（Flyconid、Fogmog）→ 雾菇 |
| 暗港 Underdocks（第一幕另一路线） | **紫灰色砖墙**、金属**管道**与大**水罐**，前景是**深蓝紫色、多孔、像珊瑚/钟乳的礁石柱**；地面是**湿漉漉的深色木栈板** | 港砖；多孔礁岩（藤壶岩）；潮木（深蓝紫木材）做栈道；铁管；淤泥/污水 |
| 巢穴 Hive（第二幕） | 琥珀/赭黄色调，地面是**六边形蜂蜡地砖**，有暗绿色**鳞片状虫巢土丘**，上面嵌着**发绿光的“眼睛”**；扭曲的深褐色**老树**根盘在地上，树皮上也有绿色眼斑 | 蜂蜡六角砖；甲壳土丘（暗绿鳞片）+ 绿眼；虫巢老树（扭曲木材）；虫卵；地洞 |
| 荣耀 Glory（第三幕） | 冷青蓝色的宫殿：碎石板地面、石拱门、火把 | **不做群系**，留给阶段 9 的高塔结构；但它的“青蓝碎石板”方块可提前在本阶段做（见第四节，可选） |

## 二、群系与变种

| 注册名 | 中文名 | 位置（气候切片，见第五节） | 地表 | 树/地物 | 氛围 |
|---|---|---|---|---|---|

> 每个变种都是独立注册的群系，便于后续生物刷新表（阶段 8）分开配置。

## 三、方块清单

“木材全套” = 原木、去皮原木、木头、去皮木头、木板、台阶、楼梯、栅栏、栅栏门、门、活板门、按钮、压力板、树叶、树苗（共 15 个，全部走原版木材的配方/标签/可燃性；**船和告示牌先不做**，告示牌需要额外的 WoodType 与渲染注册，留到后面）。
“石材套” = 本体、台阶、楼梯、墙。

### 配方与原版联动
- 木材：原木 → 4 木板；木板 → 原版的木棍、工作台、箱子（加入 `minecraft:planks`、`logs_that_burn` 等标签即可自动通用）。
- 石材：石切机配方全套；遗迹石 + 藤蔓 → 苔藓变体（同原版苔石砖）。
- 港砖 = 藤壶岩 ×4 熔炼成的“港砖砖块”合成（同原版砖块的思路）；蜂蜡六角砖 = 原版蜜脾 + 蜂蜡土。
- 所有方块进对应原版标签（`mineable/axe|pickaxe|shovel`、`leaves`、`saplings`、`walls`、`wooden_doors` 等）。

## 五、注入主世界的方式（已定）

1. **不使用 TerraBlender**（离线环境无法获取，且对 1.21.10 Forge 的支持未确认），也**不写 mixin**。
2. 在 datagen 阶段调用原版 `OverworldBiomeBuilder` 收集主世界的全部“气候参数点 → 群系”列表。
3. 选出目标原版群系的参数点，按**怪异度（weirdness）切出一窄条**交给我们的群系：
   - 密林 ← 丛林的一部分；雾菇谷 ← 繁茂丛林的一部分
   - 暗港 ← 沼泽/红树林的一部分；沉没码头 ← 海滩的一部分
   - 巢穴 ← 热带草原/恶地边缘的一部分；千孔原 ← 巢穴切片内部的高怪异度部分
   - 每个切片约占原群系面积的 1/4～1/3，保证稀有但能找到。
4. 输出覆盖 `data/minecraft/worldgen/world_preset/normal.json`（主世界换成显式的 `multi_noise` 群系列表；下界和末地保持原版引用）。
5. 影响：**只对新建的世界生效**；与其他同样覆盖 `normal` 预设的模组不兼容（后续如需兼容再改 mixin 方案）。
6. 验证：自测脚本中用 `/locate biome spirecraft:overgrowth` 等确认六个群系都能找到。

## 六、实现记录（第一批）

- 代码：`block/`（WoodSet、StoneSet、特殊方块）、`worldgen/`（ModBiomes、ModFeatures）、`datagen/BiomeData`（地物与群系 JSON）、`datagen/WorldPresetProvider`（预设覆盖）、`datagen/ModBiomeTagsProvider`。
- 群系表层由自写的 `biome_surface` 地物在 RAW_GENERATION 阶段替换（不改噪声设置的表层规则）：密林=草方块+石板路/苔藓斑块，暗港=泥+淤泥斑块，沉没码头=沙砾+藤壶岩斑块，巢穴=蜂蜡土+六角砖斑块。
- 原版地物按宿主群系的原顺序添加，自写地物统一排在各生成阶段末尾，避免“地物顺序成环”。
- 切片比例：密林=丛林最湿的 45%，雾菇谷=竹林最湿的 50%，暗港=沼泽近海 50% + 红树林近海 35%，沉没码头=海滩最湿的 30%，巢穴=（高原）热带草原最干的 40%，千孔原=巢穴怪异度最高的 30%。
- 贴图：`node tools/biome_textures.js <原版 client-extra 解压目录> [预览.png]`；木材取深色橡木/云杉/丛林木，石材取苔石砖/砖块/凝灰岩/蜜脾块，甲壳鳞片、石板路、铁管为程序绘制。
- 暂未做：船、告示牌、荣耀石板；生物刷新（阶段 8）。
