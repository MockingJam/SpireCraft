# 生物（阶段 8）— 设计稿（待确认）

## 一、技术方案（已定）

| 项 | 方案 | 理由 |
|---|---|---|
| 模型 | **原版 Java 实体模型**（`LayerDefinition` + `ModelPart`），在 Blockbench 用 *Modded Entity* 格式搭建并导出，再改写为 1.21.10 写法 | GeckoLib 不在离线 Gradle 缓存里，无法引入；原版方案无依赖 |
| 动画 | 行走/待机：`setupAnim` 里的程序动画（与原版四足、蜘蛛相同）；招式动作：原版关键帧动画（`AnimationDefinition` + `AnimationState`，监守者、嗅探兽同款） | 原版自带，Blockbench 可导出关键帧 |
| 贴图 | 按方块 UV 展开，颜色从 STS2 原画取样（与武器贴图同一套取色流程） | 风格与已有内容一致 |
| 行为 | 每个生物有一个**招式循环**（对应 STS2 的意图 Intent）：按原作的顺序/概率选招式，出招前有 0.5–1 秒的蓄势动作作为“意图提示” | 保留 STS2 的读招乐趣 |
| 数值 | 生命 ≈ STS2 生命 × 0.45，伤害 ≈ STS2 伤害 × 0.4，对标原版（僵尸 20 生命/3 伤害，掠夺兽 100/12，凋灵 300） | 平衡原版 |
| 效果 | 攻击附带阶段 2 的尖塔效果（虚弱、易伤、脆弱、中毒、力量……），新增少量效果见各生物 | 复用 |

### 精英：伯多尼斯 Byrdonis（恐鸟）

- 原作：俯冲（17）与啄击（3×3）交替；领地意识：每回合结束 +1 力量。
- MC：大型两足鸟。**俯冲**：后退助跑后扑向玩家，7 伤害；**啄击**：连续三下各 1.5；每次出招后 +1 力量（持续到战斗结束，脱战 10 秒清零）。
- 生命 60 / 盔甲 4；只在密林中稀有生成（权重低，附近有玩家时每区块最多 1 只）。
- 掉落：羽毛、生鸡肉；**50% 掉落一件普通遗物**（复用阶段 5 的遗物战利品池）。

### Boss：仪式兽 Ceremonial Beast（鹿形）

- 原作：两阶段。阶段一“踏印”获得“犁”阈值，之后反复“犁击”（18 + 2 力量）；血量降到阈值时**眩晕一回合并失去所有力量**。阶段二：兽鸣（只能出 1 张牌）、践踏（15）、碾压（17 + 3 力量）。
- MC：
  - 生命 250 / 盔甲 8，Boss 血条。
  - 阶段一：**犁击**（向前冲锋，8 伤害 + 击退，每次 +1 力量）。血量降到 60% 时**倒地眩晕 5 秒**并清除力量 → 进入阶段二。
  - 阶段二：**兽鸣**（16 格内玩家获得新效果“回响”：攻击冷却加倍 6 秒，对应“只能出 1 张牌”）、**践踏**（周围 5 格 6 伤害 + 击飞）、**碾压**（7 伤害 + 2 力量）。
  - 召唤：不自然生成。用新物品**仪式之铃**（原版钟 + 金锭 + 骨块合成）在密林中右键召唤（同凋灵式“主动挑战”）。阶段 9 的群系结构里会放置祭坛。
  - 掉落：**必掉一件稀有遗物**、一件该 Boss 专属材料“仪式鹿角”（后续可做装备）、经验 200。

### 奥斯提 Osty（亡灵契约师的骨手）

- 原作：亡灵契约师的左手，有独立生命（由“召唤 X”增加）；“为你而死”：玩家受到的攻击伤害先由奥斯提承受；契约师有专属的奥斯提攻击牌。
- MC：
  - 亡灵召唤书右键：若没有奥斯提，召唤它；若已有，消耗灵魂为它**增加生命**（每个灵魂 +4，上限 40）。取代现在的临时骷髅仆从。
  - 像驯服的狼一样跟随主人、攻击主人的目标（4 伤害，戳击动画）。
  - **为你而死**：主人在 8 格内受到攻击伤害时，伤害先转给奥斯提；奥斯提死亡时多余伤害才落到主人身上。
  - 不会自然消失；死亡后可再次召唤。

## 四、第一批模型方案（按 MODELING.md）

坐标单位为像素（1 方块 = 16）。贴图均为 64×64 或 128×128 方块 UV。

### 叶史莱姆 / 枝史莱姆（原画：蓝灰色半透明圆顶果冻，顶上长着叶子/枝杈，半闭的黄眼）
- 方块：`body` 外层 14×10×14（半透明蓝灰，阶梯状削角近似圆顶：底层 14×4×14 + 中层 12×4×12 + 顶层 8×2×8）；`core` 内层 6×5×6（眼睛所在面）；`leaves`/`twigs` 顶部 3–4 片 4×1×5 斜放叶片（叶史莱姆）或 1×6×1 枝杈（枝史莱姆）。
- 骨骼：`root` → `body`（含三层）→ `core`、`top`。小号整体缩放 0.5。
- 动画：待机时 `body` 上下压扁回弹；跳跃前压扁蓄力；落地回弹。

### 毛绒伏地虫（原画：紫色长毛覆盖的蠕虫，前端是有獠牙的圆口，身体粉褐）
- 方块：`body_1..3` 三节 8×6×7 / 7×6×6 / 6×5×5；`head` 7×7×6，前面开口（嘴的贴图）+ 两根 1×1×3 獠牙；`fur` 若干 8×2×7 紫色毛片贴在每节顶部、两侧。
- 骨骼：`root` → `head` → `body_1` → `body_2` → `body_3`（链式，便于波动）。
- 动画：行走时各节依次上下起伏；“吸气”时 `head` 与 `body_1` 放大到 1.3 倍（鼓起）；吐酸时 `head` 前探。

### 飞菇人（原画：两三朵黄色伞盖叠成的蘑菇，细长绿色菌柄，柄上有一对小手和小眼睛）
- 方块：`stem` 3×14×3；`cap_main` 10×3×10 + 6×2×6（阶梯伞盖）；`cap_side` 6×2×6 斜挂在侧上方；`arms` 2 根 1×5×1；`eyes` 贴图。
- 骨骼：`root` → `stem` → `cap_main`、`cap_side`、`arm_l`、`arm_r`。
- 动画：漂浮时整体缓慢上下、伞盖轻摆；放孢子时伞盖向下一抖。

### 尼比特（原画：蓝绿色的四足蜥蜴，宽头、背上深色斑纹、粗尾）
- 方块：`body` 8×6×14；`head` 8×5×7（宽嘴）；`tail` 4×4×10 + 2×3×6；四条腿 3×4×3。
- 骨骼：`root` → `body` → `head`、`tail`（→ `tail_tip`）、`leg_fl/fr/bl/br`。
- 动画：四足行走（原版式交替摆腿）；冲撞前低头蓄力；嘶吼时张嘴抬头。

### 缩小甲虫（原画：黄色甲壳甲虫，大复眼，头上有一对虚线状的弯触角）
- 方块：`shell` 10×5×12（两片鞘翅分块）；`head` 6×4×5；`eyes` 2×2×2 两只；`antennae` 1×1×6 弯折两段；六条腿 1×4×1。
- 骨骼：`root` → `body` → `shell_l`、`shell_r`、`head`（→ `antenna_l/r`）、六条腿。
- 动画：六足交替爬行；“缩小”时触角放出光圈（粒子）；踩击时抬起前半身。

### 伯多尼斯（原画：绿色羽毛的恐鸟，粉红钩喙，细长腿，绿色长尾羽）
- 方块：`body` 10×9×14；`neck` 4×10×4 前倾；`head` 5×5×6 + 喙 3×3×5（粉红，前端下钩 2×2×2）；`tail` 6×2×12 羽片；腿 2×12×2 + 爪 4×1×4；小翅膀 1×6×8。
- 骨骼：`root` → `body` → `neck` → `head`（→ `beak`）；`tail`、`wing_l/r`、`leg_l/r`（→ 爪）。
- 动画：两足奔跑；啄击三连（`neck` 前后快速三下）；俯冲前身体后仰。

### 仪式兽（原画：白色/浅蓝的鹿，巨大的分叉青蓝鹿角，身披金色装饰带）
- 方块：`body` 12×12×22；`neck` 6×12×6；`head` 6×7×10；`antlers` 每侧主枝 2×12×2 + 4–5 根 2×6×2 分叉（青蓝）；四腿 3×18×3（细长）；金色装饰作为贴图上的带子与挂饰（2×4×1 小方块）。
- 骨骼：`root` → `body` → `neck` → `head` → `antler_l/r`；`leg_fl/fr/bl/br`、`ornaments`。
- 动画：踱步；犁击时低头鹿角向前；眩晕时侧卧（`body` 旋转 90°）；兽鸣时抬头张嘴。
- 体型：约 2 格高、3 格长（与掠夺兽相当）。

### 奥斯提（原画：巨大的白骨左手，用手指“走路”，手腕处燃着蓝色魂火）
- 方块：`palm` 10×4×10；五根手指每根 2–3 节 2×2×4（拇指在侧面）；`wrist` 6×4×6；`flame` 若干 2×4×2 半透明青蓝（发光贴图）。
- 骨骼：`root` → `palm` → `finger_1..4`（各 → 两节）、`thumb`、`wrist` → `flame`。
- 动画：用指尖交替“行走”；戳击时食指前伸；魂火上下跳动（全亮发光层）。

## 六、第一批实现记录（v1）

- 模型：`tools/mobs/specs.js`（按 Blockbench《Minecraft 风格指南》：少方块、小部件用双面贴片、顶/正面亮、底/背面暗、无随机噪点；史莱姆基于原版史莱姆 8³ 外壳 + 6³ 内核改）→ `tools/mobs/build_mobs.js` 生成 `client/model/MobLayers.java` 与 `textures/entity/*.png`。

- 自测：生命值、史莱姆分裂、缩小的施加与解除、仪式兽二阶段。
