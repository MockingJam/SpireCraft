# 贴图风格规范

> 来源：对 36 张原版物品贴图的观察与统计，以及三轮用户反馈（2026-11-12）。
> 所有新贴图在提交前，都要和同类原版贴图**并排放大对比**，并对照下面的“检查清单”。

## 像素画美观性原则（2026-11-13 总结）

> 来自几十轮反馈。光影和光泽只是其中一项；更重要的是“放进 Minecraft 里看起来自然”。

1. **先融入环境，再求出彩**：贴图是摆在原版物品、方块旁边看的。配色从原版同类材质取（铁剑的铁、木棍的木、金、钻石、下界合金、皮革、骨头、石英），描边、受光方向（左上）、对比度、颜色数都和原版一致。自创的颜色只用在少量点缀上。
2. **按材质画，不一刀切**：金属有锐利的高光和金属光泽；液体有弧形的反光条，没有宝石那样的星点；宝石/水晶有切面和闪光；布料、木头、骨头是哑光的；标志/符号（效果图标）保持简洁，平面或轻微明暗即可。“精致”不等于“对比度高”。
3. **原版已有的形状直接用原版的**：剑、盾、药水瓶、粉末堆、锭……沿用原版的轮廓和明暗结构，只换颜色和少量细节，自然就和原版统一。
4. **轮廓先行**：在原尺寸下只看剪影就要认得出来（锚、镰刀、刺球、苦无）。细部件至少 1–2 像素，孔洞和缝隙要留得出来，相邻部件之间留空，不要粘成一团。
5. **明度结构清楚**：大块的亮/中/暗分区要明确，主体和背景、部件和部件之间拉开明度差；细节服从整体，不要满屏噪点。
6. **配色协调**：一件物品一组颜色（主材质 + 1 个点缀色），色相相近或互补，避免多种饱和色互相抢；暗部偏冷/偏暗色相，亮部偏暖。角色色调是倾向，不是硬性要求。
7. **对称和秩序**：对称物体（齿轮、刺球、盾）要严格对称；重复元素等距或自然错位；像素曲线用递减步长，避免锯齿。
8. **尺度统一**：物品大小参照原版（水果不超过苹果）；只有确实需要细节的大型武器才用 32×32，并且画法仍贴近原版。
9. **参照有出处**：STS2 内容先看原图/卡牌插画抓特征，再用 Minecraft 的画法重画；必要时参考泰拉瑞亚/灾厄的武器造型。

## 总原则

**杀戮尖塔中有的物品：整体样貌参考杀戮尖塔，形态和纹理参考 Minecraft。美观性与合理性兼备。**

- “样貌”= 这是什么东西、它的识别特征和主色（STS2 的芒果是黄橙色带绿叶，带骨肉是一块烤肉穿着骨头，熔岩石是带发光裂缝的黑石）。
- “形态和纹理”= 视角、尺寸、轮廓处理、光影、材质颗粒，都按原版的画法。
- “合理”= 符合现实常识：草莓籽是散乱分布的；芒果只有叶子是绿的、果皮是黄到橙的连续渐变；水果是饱满的。

## 统计结论（原版物品）

| 指标 | 原版平均值 | 含义 |
|---|---|---|
| 每张颜色数 | 约 9 | 一个色系 + 至多 1 个点缀色 |
| 轮廓亮度 / 内部亮度 | 0.47 | 轮廓是**同色系的深色**，不是黑色 |
| 左上与右下亮度差 | 约 35（0–255） | 光从**左上**来，整个物体有明显的明暗过渡 |
| 占用尺寸 | 约 13×13 | 物体基本占满 16×16，四周留 1–2 像素 |

## 规则

### 形状与构图
1. **视角**：细长物品 45° 斜放（左下 → 右上）；圆形水果正面略斜，果柄和叶子偏右上。
2. **饱满**：水果、肉类等用平滑的几何形状生成（圆、平滑并集、对角椭圆），轮廓圆润对称，不歪扭、不干瘪；尺寸对齐原版苹果（约 12×14）。
3. **自然排列**：籽、斑点、矿点等重复元素**随机散布**（抖动网格），绝不排成整齐的行列。

### 光影与颜色
4. **体积光照**：每个部件当作有弧度的曲面，按表面朝向计算明暗——受光面（左上）→ 明暗交界 → 背光面（右下）连续过渡。
5. **高光是渐变**：镜面高光从最亮色向外逐级过渡、铺开数个像素，不是孤立的一个亮点。
6. **同一表面的颜色变化必须是渐变**：如芒果黄→橙，用混合色阶 + 有序抖动过渡，**不能出现生硬的色带分界**。不同部件（叶子与果肉）之间才有明确分界。
7. **轮廓**：同色系最暗色；受光侧略亮，背光侧最暗。
8. **配色**：6–8 级色阶，暗部偏冷/偏红、亮部偏暖/偏黄；饱和度要足（水果鲜艳但不刺眼），高光不要冲淡固有色。
9. **光泽要分材质**：金属/宝石 = 高镜面反射、亮高光（矿点、锭）；果皮 = 中等；粗糙物（岩石、烤肉）= 低镜面 + 细微颗粒噪点。

### 与原版同类物品
10. **有原版同类的，以原版贴图为底，只换材质**：锭 ← 铁锭/金锭，粗矿 ← 粗铁/粗金，储存方块 ← 铁块/金块/粗金块，晶簇 ← 下界石英，工具/盔甲 ← 铁制品，穿戴盔甲 ← 原版 UV 布局与明暗。
11. **与原版物品同源的，直接用原版的纹理**：紫水晶茄子由原版紫水晶合成，表皮直接取原版紫水晶块的纹理，而不是画成真实的茄子。
12. **矿石**：原版母岩 + 矿点。矿点像原版一样**形状多变但大小、密度一致**，彼此分离；每个矿点单独计算光照，保留金属/晶体光泽，避免“老版本”那种平涂、粗糙的感觉。

### 方块
13. 可平铺，无透明边，块边缘不描边；明暗靠颗粒与色块。

### 第四轮经验（2026-11-12）
14. **盔甲是板甲**：以原版**下界合金/钻石盔甲**为底（板甲结构、金属光泽），**不加白色铆钉点**，板块与缝隙的色差要小（缝隙只比板面暗一两级，绝不能画成黑色）。
15. **控制对比度**：金属块、锭、盔甲映射色阶时只用色阶的中段（约 10%–90%），避免黑白跳色造成“粗糙”感；参考 Create 等高质量模组：平面干净、噪点少、对比柔和。
16. **矿石沿用原版矿点**：取原版同类矿石的矿点（包括矿点外圈的深色边），**镜像 + 平移**后放到母岩上，再换材质色阶——形状保持原版的自然感，但像素位置与原版不同。矿物颜色要和母岩拉开（黑钨矿用中灰褐 + 钢蓝高光，而不是纯黑，否则在石头上看不见）。
17. **流体从缝里流出来**：熔岩石不是“点缀几个亮点”，而是裂缝里发光的熔岩（中心最亮），裂缝两侧的岩石被烤红，熔岩从底部的缝口滴出、越出轮廓。
18. **液滴是圆润的**：血滴 = 圆形底部平滑收成一个柔和的尖，全程没有直边；内部的火焰也用同样的平滑形状。
19. **粉末是锥形堆**：中间高、两侧缓，整体平滑渐变，零星亮点表现颗粒（参考 Create 的黑曜石粉）。
20. **小元素要看得见**：草莓籽等点缀用比底色明显更亮的色阶（即使在背光面也能分辨），并在原尺寸下确认可见。
21. **比例**：附属部件不要喧宾夺主（带骨肉的骨头只露出一小截骨节）。

### 第五轮经验（2026-11-12）
22. **矿点不贴边**：沿用原版矿点时只做镜像/上下翻转，不做会“绕回”的平移（平移会把矿点推到方块边缘，被切成半个）。
23. **金属要亮、要反光**：金属色阶要一直延伸到接近白色的高光（奥利哈钢从深绿到近白绿），整体偏亮（gamma < 1），这样才读得出“金属”而不是“绿色石头”。
24. **盔甲要有自己的纹理**：可以借鉴下界合金甲的板甲感，但纹样自己设计（如斜向拉丝高光线 + 少量浅刻线），不照抄原版纹样。
25. **玻璃感 = 强而集中的镜面高光 + 一道弧形反光**：燃烧之血做成玻璃泪滴形血珠，内部是由下往上燃烧的几簇火苗（自发光、中心最亮），而不是“红色外圈 + 黄色中心”。
26. **遗物按 STS2 原画的体量画**：钨合金棍是粗短的金属圆柱，能看到端面，而不是细长的棍子。

### 第六轮经验（2026-11-12）
27. **均匀 ≠ 整齐**：草莓籽这类点缀用“错位网格 + 小幅随机偏移”，既分布均匀又不排成行列（纯随机会出现扎堆和空白）。
28. **有机轮廓要做平滑处理**：生成形状后去掉孤立突出的像素、补上凹口，避免尖角和锯齿感（草莓尖端、梨颈）。
29. **“棍”要细长**：识别特征是长宽比——棍子贯穿整条对角线、细，两端有端面和箍，而不是粗短的柱体。
30. **形状对称、主体居中**：带骨肉的骨头从肉的正中穿过，两端露出的骨节一样短，正面主要是肉。
31. **粉末物品沿用原版粉末堆轮廓**（萤石粉/红石粉），换配色并加点缀（星系尘埃 = 星空紫色粉堆 + 小星光）。
32. **亮度要适中**：金属有光泽但不能整片发白；高光只在受光面的一小片。
33. **盔甲纹理要看得见**：板块接缝（低一级）+ 斜向高光线，在原尺寸下也能分辨。
34. **内部发光要照亮周围**：玻璃血珠里的火焰会把附近的血液照亮成暖红，越近越亮（innerGlow），这样才有“里面在燃烧”的感觉。
35. **矿物选对原版来源**：深色矿物（黑钨矿）用煤矿的矿点（黑色团块）为底，浅色金属才用铁矿；选错来源会像地衣/苔藓。

### 第七轮经验（2026-11-12）
36. **棍类物品的长度与端面**：遗物棍不必贯穿整个对角线（约 3/4 即可）；圆柱要稍粗（直径 ≥4 像素），端面画成**完整的椭圆**（亮面 + 一圈深色边），才能读出“截面是圆的”。
37. **骨头两端要醒目**：骨节用两个圆凸（左右各一）组成“狗骨头”轮廓，比肉的轮廓明显突出。
38. **盔甲纹理不用浅色条纹**：只保留板块接缝（比板面暗一级），高光上限控制在色阶 ~80%，避免一道道白线。
39. **点缀均匀分布**：草莓籽用严格错位网格（不抖动），在原尺寸下逐个检查有无挤在一起的籽。
40. **液滴对称圆润**：燃烧之血的轮廓左右对称，内部火焰也对称；火焰色阶从深红平滑过渡到黄，并通过 innerGlow 加大照亮半径，红与黄之间不出现硬边。
41. **用户指定“不改颜色”时**，保留原配色，只改形状或细节。

### 第八轮经验（2026-11-12）
42. **圆柱要按圆柱打光**：两侧是平行直边，明暗沿**横截方向**变化（受光边 → 沿长度方向的一条高光带 → 背光边逐级变暗），远端是完整的浅色椭圆截面，近端是凸出的半个椭圆。不能用“整体体积光”把它画成药丸。
43. **标准血滴**：下半部分是完整的半圆（形状必须完全在 16×16 内，被画布边缘截掉就会变成平底），上方两侧收成一个尖。
44. **金属盔甲要有光泽**：加大对比（色阶 2%–90%，gamma < 1），再叠加一层从左上（亮）到右下（暗）的整体光泽渐变；不靠白色条纹。

### 第九轮经验（2026-11-13）
45. **血滴用标准泪滴曲线**：半宽 w(v)=√(1−v²)·((1−v)/2)^0.6（v 从底部 −1 到尖端 +1），底部是平滑的圆、两侧连续收成尖，没有“肩膀”；玻璃高光参考常见血滴插画：右侧沿边一道弧形白光 + 右上一小道短光，整体保持饱和的红，不要把受光面冲成粉色。
46. **沿用原版外形时要略作变化**：硫磺用石英的晶簇，但做水平镜像（不能上下翻转，晶体会朝下）。
47. **主体要够大**：带骨肉的肉占画面大部分，骨头只在两端露出骨节。
48. **水果颜色可以有多段渐变**：芒果靠近叶片处微微泛绿（绿黄只占前 20%，暗部不能发绿发灰），再过渡到黄、橙；叶片要够大，能一眼认出。
49. **遗物按用户认可的版本微调**，不要每轮推翻重画（钨合金棍回到第一版的长度，只改成圆柱打光）。

### 第十轮经验（2026-11-13）
50. **轮廓不要用色阶最暗的那一级**：原版的轮廓是同色系的深色，不是近黑。血滴轮廓取血色色阶的第 4 级（深红），硫磺取色阶 18% 以上（深赭黄），这样边框细而柔和。
51. **小尺寸的关键轮廓手工定宽**：16×16 的血滴，每行宽度直接写表（2,2,4,6,6,8,10,10,12,12,12,10,8,4），比公式更容易得到平滑、对称的台阶。
52. **对称物体两端处理要一致**：钨合金棍两端都是同样的圆形端盖 + 同样位置的环箍。

### 第十一轮经验（2026-11-13）
53. **像素曲线靠“步长递减”**：轮廓每侧的水平步进按 3-2-2-1 行递减（再接竖直段），就是一条平滑的弧；步长忽大忽小就会出现锯齿。
54. **借鉴原版不等于镜像**：硫磺用自己的生成器画晶簇——沿用石英的画法（尖顶棱柱、左面亮、右面暗、中间色调的描边），但晶体的数量、大小、倾斜和前后层次都自己定；色阶最高只到浅黄，不出现白色。
55. **圆柱的辨识度**：棍子要够粗（直径约 5 像素），远端画出完整的浅色圆形端面 + 一圈边，近端是同样轮廓的弧形，明暗沿横截方向变化。

### 第十二轮经验（2026-11-13）
56. **液滴的重心在下面**：尖端短（2 行）、往下迅速变宽，最宽处在下三分之一，下半部分饱满。
57. **晶簇要向下收拢**：两侧晶体向外倾斜、底部聚在一起，整体呈扇形，而不是几根直立的柱子并排。
58. **圆柱加一点透视**：朝向观察者的一端略粗并露出圆形端面，远端略细，这样不用很粗也能读出圆柱。
59. **“缩小一点点”就是小幅调整**：调参后先看效果，过头了要退回中间值。

### 第十三轮经验（2026-11-13）
60. **血滴 = 圆 + 细尖**：下半部分近似一个直径约 10 像素的圆（不要更宽），上面接一个细而不短的尖（约 4 行，宽 2→4）。行宽表：2,2,4,4,6,8,8,10,10,10,10,8,8,4。
61. **晶簇里每根晶体都要有点倾斜**：完全竖直的那根会显得突兀，中间的也要略微偏一点。

### 第十四轮经验（2026-11-13）
62. **内部渐变用连续的“热度场”**：火焰不要分成“外焰 / 内核”两个色块，而是按“离火焰边缘多深 + 离底部多近”算一个连续热度，量化成 7 级（血红 → 深橙 → 橙 → 黄 → 淡黄），用 4×4 有序抖动过渡，最低一级接近血色，这样与血液自然相接。
63. **晶体可以上细下粗**：中间那根底部宽、顶部窄，才不像一根直柱；晶簇整体要足够高。
64. **用户认可的版本就是基准**：钨合金棍回到第一版（粗圆柱、左下端面、整体体积光），不再加透视。

### 第十五轮经验（2026-11-13）
65. **血珠不加白色高光**：燃烧之血只用红色系的体积光和左缘的淡红反光，白色会显得像塑料。
66. **晶簇的绘制顺序决定倾斜能否被看见**：主晶体（饱满、上细下粗）先画在后面，两侧明显外倾的晶体画在前面，从同一个底座散开；否则侧晶体被主晶体挡住，倾斜看不出来。

### 遗物图标经验（2026-11-13）
67. **先看 STS2 原图再画**：在 wiki 上打开对应遗物图（slaythespire.wiki.gg/images/StS2_<名字>.png），取主色（像素采样）和轮廓特征。例如锚是蓝色油漆 + 米色绳子，小血瓶是圆肚药瓶 + 橙色瓶塞，铜质鳞片是三块多面体铜片。
68. **大形体要“圆”光照**：渲染器的 profile:'round' + bulge（高度随形体大小变化），整块形体从受光面到背光面都有渐变，不会中间一片平；rim 给背光侧一点反光。
69. **深色细节用固定深色**：眼窝、笔尖缝、镂空不参与体积光照，否则会被照亮而看不见。
70. **复杂轮廓手绘像素图**：锚、手里剑、面具、蜥蜴尾巴、金刚杵这类细节多的图标，在 16×16 上用公式生成会锯齿、断裂；直接手写像素图（可镜像对称），光影仍交给渲染器。
71. **描边不要喧宾夺主**：细小部件尽量加粗到 2 像素；描边用色阶第 2 级（outlineIdx: 1），不用近黑。

### 遗物图标第三轮（2026-11-13）
72. **用原图描轮廓**：在浏览器里把 STS2 原图缩到 14×14（只算非描边像素，按饱和度区分灰色描边），得到真实比例的轮廓，再手工清理成 16×16 像素图——形状比凭印象画准得多（红面具、红头骨、锚、金刚杵）。
73. **对比度要克制**：amb≈0.2、kd≈0.6、ks≤0.45；颜色取原图的中间调，不要把最亮的高光拉满（锚、燃烧之血）。
74. **斜细线用超采样**：对角方向的细部件（笔尖、手里剑、沙漏）每像素 4×4 采样、覆盖 ≥40% 才填；比单点采样连贯。
75. **镂空要真的留空**：金刚杵的花苞是张开的爪，像素之间留出透明缝，描边会自动勾出层次；画成实心就会像一根棒子。
76. **药瓶类按原版尺寸**：小血瓶参照原版药水瓶的轮廓与大小（瓶塞 3 行、瓶颈 2 行、瓶身 8 行）。
77. **视角可以换**：沙漏用倾斜的 3/4 视角，木盘看得到顶面；手里剑、锚斜 30–45°，更生动。

### 遗物图标第四轮（2026-11-13）
78. **相邻的尖端会被描边粘在一起**：两个部件的末端之间至少要隔一个“上下左右都不挨着实心像素”的透明格，否则描边会填满缝隙。金刚杵的侧爪要比中间的尖刺短，末端朝前，四个爪用“沿轴镜像 + 中心对称”画出来，保证对称。
79. **1 像素的斜线不加描边会散成点**：细部件要么保留描边，要么加粗到 2 像素；不能简单去掉描边。
80. **尺寸要和同类图标对齐**：锚、骷髅不要顶满 16×16，留 1–2 像素边；鳞片这类块状物要足够宽才饱满。
81. **小的面部特征至少 2 像素**：面具的眼孔 1 像素在原尺寸下看不见。
82. **刃要有尖**：手里剑每片刃做成从中心向外收窄的三角形，而不是等宽的条。
83. **长条形生物粗细要一致**：蜥蜴尾巴除了末端收尖，其余部分保持 3 像素左右的均匀粗细。

### 遗物图标第五轮（2026-11-13）
84. **孔洞之间要隔开**：骷髅的眼窝、鼻孔、嘴之间至少隔一整行/列实心像素，否则描边和暗色会把它们连成一个大洞。
85. **退回比硬改好**：用户说上一版更好时，以上一版为底只修具体问题，不要另起炉灶。
86. **三股分开但允许接触**：金刚杵侧爪向外弯、再弯回到尖刺末端相接，中间留出镂空——接触点只在末端，能看出是三根。
87. **“看不出是什么”就换成最经典的造型**：沙漏用正立的经典轮廓（上下木盖、漏斗形玻璃、上方剩余与下方堆积、中间一条细流），比倾斜的 3/4 视角好认。

### 遗物图标第六轮（2026-11-13）
88. **只改用户点名的那一点**：“宽一点”只改宽度，不顺手改视角/排列；“细一点”是变细，不是删掉。改之前先确认要保留的特征（锚底部的尖弧、面具左侧的角）。
89. **对角线物品先分配长度**：金刚杵从中心沿轴线逐格分配：宝珠 → 护环 → 颈 → 两格长的爪笼 → 一格尖端，中段和两端的比例才对。
90. **骷髅可借鉴泰拉瑞亚**：正面、大而圆的颅骨、大眼窝、窄小的下颌和一排牙齿，整体约 10×11 像素，比照搬 STS2 的大下巴更好看。
91. **用户不要正视图时**：保留最好认的经典轮廓，再整体倾斜约 20°，用超采样保持边缘干净。

92. **斜向 1 像素线显细**：金刚杵的侧爪要在外侧再加一排像素，做成 2 像素粗的阶梯线；宝珠和护环也加宽。蜥蜴尾巴主体约 4 像素粗，只在最后两行收尖，尖端不能碰到画布边缘。

93. **大块光滑曲面会出现“噪点”**：距离场是阶梯状的，算出的法线忽左忽右，光滑石头上就有斑点。渲染器的 smoothH（对高度图做 2 次 3×3 平滑）可以去掉。
94. **镂空多的物品用浅一点的描边**（outlineIdx 3），否则缝隙里全是深色描边，整体显得粗重。
95. **沙漏的木盖不要比玻璃宽太多**：盖子约 9 像素宽、1–2 行厚，玻璃最宽处略窄于盖子。

96. **镂空多、部件细的物品：本体用接近单一的中间色，描边用最深色**。光照范围收窄（amb≈0.36、kd≈0.34、ks≈0.15），本体各处颜色相近，深色描边和镂空就能把三股尖刺清楚地勾出来；不要只把个别尖端像素压暗。

97. **细节密集的小物件用手工分色，不用体积光**：每个像素按受光情况直接指定色调——上/左边缘朝空 → 亮边，下/右边缘朝空 → 暗边，其余 → 中间调；宝珠左上加高光，护环用深色带分隔。五级色调之间拉开明显的差距，每个部件都有清楚的边界（金刚杵）。体积光适合大块曲面，在 1–2 像素宽的部件上只会把细节抹平。

### 第三方反馈：尺寸、状态图标、角色风格（2026-11-13）
98. **物品大小向原版看齐**：原版很多物品不占满格子（苹果约 12×14 含果柄）。水果做到苹果大小或略小，草莓只有约 9×11；遗物为保留特征可以占满。
99. **状态图标 = STS2 图形 + 原版画法**：形状取 STS2 的 Icon_*（力量=红剑、易伤=裂开的心、脆弱=裂开的蓝盾、灾厄=墓碑……），画法照原版效果图标：干净的轮廓、3–4 个色调、左上受光、深色描边、无投影、无噪点。
100. **武器必须有特色，不能把原版换色**：每件武器有自己的轮廓（V 形回旋刃、蛇形刃、柳叶形小刀、刺球流星锤、弯柄大镰刀），并带上所属角色的元素。
101. **角色配色**：铁甲战士=偏红、带血迹、刀刃偏黑的重金属（玄铁微红）；静默猎手=绿色、白绷带、绿布、淡绿毒液、蛇；储君=橙色为主，辅以天蓝和深蓝/紫的夜空、星辰与太阳；亡灵契约师=紫色、大镰刀、弯曲的柄；故障机器人=淡黄外壳、蓝色充能球、灰色导线与管道。
102. **方块不要黑边**：重新着色的方块把色阶下限抬高（奥利哈钢块 0.32），避免描边变成近黑。

103. **状态图标用平面画法**：照 STS2 的 Icon_* 原样画——每个形状只有明暗两色（左亮右暗），深色描边，不做体积光。具体：缓冲=三层错开的方块（橙/黄/绿）、荆棘=棕黄色的星形刺球、人工制品=金色齿轮、灾厄=刻着骷髅的灰绿墓碑、易伤=圆润的裂心、无形=黑色云团中的灰盾。原版已有的效果（中毒）直接用原版图标。
104. **武器先看卡牌插画**：回旋剑是弯刀、淬毒刺击是半截浸在亮绿毒液里的直刃、小刀是带环孔的无柄刃、弹跳药瓶是带螺栓的金属罐、君王之剑是宽阔的多面水晶刃（剑格处一颗星）、镰刀刃是灰色钢、利爪是三道炽红的爪痕、防空炮是装在奶白机械臂上的深灰炮管。
105. **角色色调是整体倾向，不是每件都要上色**：亡灵契约师的镰刀刃仍是灰钢，紫色只用在缠布等点缀。
106. **小孔洞要用最深描边**：1–2 像素的孔（小刀的环孔）用 outlineIdx 0，否则描边色接近本体暗部，孔看不出来。

107. **状态图标用 18×18**（与原版效果图标同尺寸），在平面的 STS2 图形上加原版式的精致处理：边框/护边、体积光、金属光泽、更多细节（人工制品=12 齿金齿轮 + 内环 + 轴心，带高光）。
108. **大型武器用 32×32**：流星锤、回旋刃、君王之剑、坠星权杖、两把镰刀、散射炮。多出来的像素用于细节（链环、铆钉带、宝石、刃口高光、刻面、缠带纹路），画法参考泰拉瑞亚/灾厄：清晰的 1 像素深色描边、分明的明暗、刃口高光、护手宝石。小件（匕首、小刀、药瓶、罐子、骨笛、爪、核心）保持 16×16。
109. **配色要协调**：每件武器只用一组相互搭配的颜色（铁甲战士=暗红铁 + 皮革红 + 黄铜；储君=水晶蓝 + 鎏金橙；亡灵契约师=钢灰 + 灰褐木/骨白 + 少量紫；故障机器人=奶白壳 + 炮铁 + 一颗蓝球）。
110. **渲染器与尺寸无关**：draw_pixel_art.js 的 map 类型按 rows.length 处理任意尺寸；pixel_art_defs.js 的 drawAAAt(N, fn) 让同一套 16 单位坐标的造型输出 16/18/32 像素。替换数字常量时注意别改到小数（0.16）。

111. **效果图标按材质处理**：盾和剑直接用原版抗性提升/力量/虚弱图标重新着色；血滴=液体反光（弧形浅色条 + 小点），不要宝石星点；缓冲、充能球=平面符号（充能球用正八边形）；齿轮=金属光泽；描边用同色系深色而不是近黑。
112. **武器配色以原版材质为主**：从原版贴图采样的铁/木/金/钻石/下界合金/皮革/骨/石英色阶，角色特色只放在点缀（红宝石、毒液、魂火、紫缠布、蓝色充能球）上。

## 检查清单（每张贴图）

- [ ] 一眼能认出是什么（与 STS2 原画或现实对照）
- [ ] 轮廓饱满、对称、无多余凸起或缺口
- [ ] 从左上到右下有连续明暗，高光是一小片渐变
- [ ] 同一表面的颜色过渡平滑，无生硬色带
- [ ] 重复元素随机散布
- [ ] 与最接近的原版贴图并排看，风格一致、不显得更粗糙或更平
- [ ] 金属/盔甲：无白点、无黑缝，对比柔和，有光泽
- [ ] 在 1× 原尺寸下看：点缀元素仍可见，轮廓仍清楚

## 渲染器对应

`tools/draw_pixel_art.js`：
- `shade:'volume'`（默认）：体积光照（漫反射 + 柔和镜面高光）；`groups` 让多个区域共用一个曲面（草莓籽随果实一起受光）。
- `blend`：同一区域在两条色阶之间按方向渐变，有序抖动过渡（芒果、梨子）。
- `tex` / `texMix`：把原版纹理的明暗叠加到区域上（紫水晶茄子用原版紫水晶块）。
- `shade:'glow'`：自发光，中心最亮（熔岩脉）。
- `reshade`：以原版同类贴图为底，换色阶 + 叠加细节。
- 几何辅助：`draw / circ / smin / seg / scatter / oreDeposits`（`tools/pixel_art_defs.js`）。

## 方块纹理规则（用户 2026-11-15） / Block texture rules

- 深色点要少，只用孤立的 1–2 像素，不要成块成团（避免密集恐惧）。Few dark dots: only isolated 1–2 px, never clusters.
- 整块颜色协调，没有特殊需要时只用一个色调。One harmonious hue per block unless there is a reason.
- 要有一点亮暗变化和色差，但对比度不能夸张；整体协调的同时要能看清纹理。Some light/dark variation, moderate contrast, texture still readable.
- 考虑光影和方块之间的衔接（纹理要无缝平铺）。Mind shading and seams between blocks (tile seamlessly).
- 例：巢岩 = 原版石头纹理换成单一琥珀褐色，只点缀几个单像素。Example: hive rock is vanilla stone's grain in one amber-brown with a few single pixels.

## 生物模型（2026-11-18 用户反馈）/ Mob models

113. **先列特征，再按部位建模**：每个生物先从 STS2 原画和现实中的同类动物列出特征（胸、颈、肩、腹、背、腰、胯；大腿小腿粗细；眼、牙、耳、嘴大小；毛发或羽毛形态；手掌大小），再逐个部位按尺寸做。体型越大越不能用几个方块糊弄。List the features first (from the STS2 render and the real animal), then build part by part; the bigger the monster, the less a few boxes will do.
114. **人形不套原版人形**：比例按原画（矮壮、瘦高、驼背、大头……），用 `tools/mobs/kit.js` 的 `figure()` 单独设定每段尺寸。Humanoids keep their own STS2 build, never the vanilla player.
115. **不要台阶和锯齿**：同一部位也可以用斜方块拼（`kit.octo` 倒角棱柱、`kit.rotBox` 斜块），Boss、精英和大型怪尤其如此。No stair-stepped or jagged outlines: use bevelled prisms and tilted cubes, even within one part.
