# 状态效果（阶段 2）

STS2 的效果按“层数”计算，Minecraft 的 MobEffect 用 **等级（amplifier）+ 持续时间** 表示。约定：**层数 = amplifier + 1**；回合制的“持续 N 回合”换算成 N × 5 秒（暂定，平衡时再调）。

## 已定决策（2026-11-12）

1. **护盾 = 原版伤害吸收（Absorption，黄心）**。敏捷、脆弱修改的是“获得的伤害吸收量”。
2. **力量对远程攻击同样生效**：弓、弩、三叉戟投掷等由玩家/生物发射的投射物伤害都 +层数。虚弱同理作用于远程伤害。
3. **灾厄处决对 Boss 生效**（包括末影龙、凋灵等原版 Boss 以及本模组 Boss）。

## 计算顺序

与 STS 一致：**先加减，再乘除**。

1. 攻击方：基础伤害 + 力量层数 → ×0.75（若攻击方虚弱）
2. 受击方：×1.5（若易伤）
3. 缓冲：若受击方有缓冲，本次伤害归零并消耗 1 层（发生在原版护甲与伤害吸收结算之前）
4. 其余交给原版：护甲、附魔保护、伤害吸收、生命

获得伤害吸收时：基础量 + 敏捷层数 → ×0.75（若脆弱）。

## 实现与测试

- 代码：`effect/ModEffects`（注册）、`effect/SpireEffectEvents`（规则）、`effect/StackChanges`（层数消耗排队到 tick 末尾）、`effect/SpirePoisonEffect`
- 灾厄处决使用自定义伤害类型 `spirecraft:doom`（无视护甲、无敌帧、抗性等），死亡信息“被灾厄吞噬了”
- 自动化自测：`powershell -File tools\selftest.ps1`，在无头服务器上用铁傀儡逐条验证以上规则，输出 PASS/FAIL（当前 22/22 通过）
- 图标：`textures/mob_effect/*.png`（18×18，初版），Blockbench 工程 `art/effects/mob_effect_icons.bbmodel`
- 命令示例：`/effect give @s spirecraft:strength 30 2`（3 层力量，30 秒）
