# 结构（阶段 9）Structures

风格：古代欧式传说 / 奇幻，不出现现代元素；以原版方块为主、模组方块点缀。每个结构都按 STS2 的群系与事件取材（事件名来自 slaythespire.wiki.gg 的 *Slay the Spire 2:Events* 列表）。
Style: ancient-European fantasy, vanilla blocks first with mod accents; each structure draws on an STS2 zone or event.

> v3.2 设计稿，确认后再动手。只影响新生成的区块。
> v3.2 design draft, to be confirmed before building. Only new chunks are affected.

## 一、做法 How they are built

| 类型 | 用于 | 做法 |
|---|---|---|
| **模板结构**（jigsaw） | 有固定造型的建筑：营地、码头、帆船、灯塔、房屋、遗迹、小屋… | 用脚本 `tools/structures/*.js` 直接写出 `.nbt` 结构模板（与原版结构方块保存的格式相同），再写 `worldgen/structure`、`structure_set`、`template_pool` 的 JSON 和 `has_structure/*` 群系标签。可加入原版的 `structure_processor`（随机把部分方块换成苔藓/裂纹/空气）做出破损感。 |
| **地物结构**（代码生成） | 必须贴合地形的：瀑布后的密室、石中剑、帝王蟹洞、盘丝巢穴 | 写在 `V2Features` 里，跟瀑布、巢一样按地形挖出/搭建，内部再用模板摆家具。 |

- 战利品：每个结构一张 `chests/*` 战利品表（原版物品为主 + 模组材料、药水、少量遗物），平衡对照原版同级结构（村庄 / 沉船 / 海底遗迹 / 掠夺者前哨）。
- 刷怪：营地/领地内放对应群系生物的刷怪笼或结构生成时一次性放置生物（如同族、多尼斯异鸟）。
- 密度：小结构（遗迹堆、废机械堆）约每 20–30 区块一个；中型（营地、灯塔、帆船）约每 32–48 区块；大型（同族领地、帝王蟹洞）约每 64+ 区块。最终数值做出来后截图再调。

## 三、会刷新的商人 Respawning merchant（STS2 *The Merchant*）

- **刷新**：像原版流浪商人。每 24000 tick（一天）检查一次，成功率与原版相同：25% → 失败后 50% → 75%（成功后重置为 25%）；与原版流浪商人分开计数；在玩家附近 48 格内的地表生成，带一只驮物生物（羊驼，原版毛毯换成紫色）。
- **停留**：48000 tick（两天）后消失，像流浪商人一样喝隐身药水离开。
- **外观**：STS2 的商人（披着大斗篷、背着货架的商人），自己做模型；带他的地毯（他站在一块地毯上摆摊）。
- **交易**：用绿宝石，每次出现随机抽取：
  - 3–5 种**药水**（模组药水）；
  - 1–2 件**遗物**（普通/罕见，价格高）；
  - 材料（硫磺、星系尘埃等）；
  - **“移除服务”**：付绿宝石移除一件物品上的一个诅咒附魔（对应 STS2 的删牌）。
- 交易次数有限（每项 1–3 次），不会补货——想要新货要等下一个商人。
- 此外营地、码头可能有一个**不移动的商人摊位**（结构生成的固定商人），货物同样随机。

## 六、实现记录（v3.2）Implementation record
