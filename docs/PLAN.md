# SpireCraft 开发计划（杀戮尖塔2 主题 Minecraft 模组）

> 环境：Minecraft 1.21.10 / Forge 60.1.0 / Java 21（共用 `../Forge1.21.10-Lazypack` 的 JDK 与 Gradle 缓存）
> 模组 ID：`spirecraft`（暂定，可在阶段 1 开始前更改）　包名：`com.mockingjam.spirecraft`
> 美术：Blockbench + blockbench-mcp，工程文件放 `art/`，导出结果放 `src/main/resources/assets/spirecraft/`
> 参考资料：生物/遗物/药水形态以 sts2.huijiwiki.com 等正规资料为准（见 `docs/MODELING.md`）；贴图在原作风格基础上**重新绘制为像素风**，不直接搬运原作素材。

## 总体原则

1. **先机制、后内容、最后玩法模式**：效果系统是药水、遗物、武器的共同基础；原版模式的内容（方块/物品/生物/结构）是爬塔模式的素材库。
2. **每个阶段都能进游戏验证**：阶段结束时 `runClient` 实测，确认无误再进入下一阶段。
3. **内容表驱动**：每类内容先在 `docs/design/` 里列表（名称、来源、效果、配方、贴图状态），再批量实现。
4. **数据生成（datagen）优先**：模型 JSON、语言文件、配方、战利品表、标签尽量用 `runData` 生成，减少手写 JSON 出错。
5. **数值按原版平衡，不照抄 STS2**：怪物血量与伤害、药水、遗物、武器工具的数值都以原版同级内容为参照（如普通怪 ≈ 僵尸 20 血 / 3 伤，精英 ≈ 掠夺者–卫道士，Boss ≈ 凋灵/监守者量级；武器在铁–下界合金区间内定位）。STS2 只提供“效果的形态”，不提供数字。
6. **融入原版体系，而非另起炉灶**：
   - 掉落物可以包含原版物品，模组材料可以参与原版配方，原版材料也可以合成模组物品；
   - 群系和建筑中大量使用原版方块，模组方块用来点出风格；
   - STS2 中的东西能用原版变种表达的就用变种（如宝箱 = 原版箱子的变种：不同外观与配方）。
7. **世界观风格**：古代欧式传说 / 奇幻风格，不出现现代元素。可以为群系自创建筑（例如暗港的码头、灯塔），不局限于需求清单。

## 美术工作流（Blockbench MCP）

1. 打开 Blockbench（MCP 插件随 Blockbench 自动启动服务，端口 39287）
2. 由 AI 通过 MCP 建模/画贴图/做动画，工程存 `art/models/<类别>/<名称>.bbmodel`
3. 导出：方块/物品 → Java Block/Item JSON + PNG；实体 → Java 实体模型（或 GeckoLib 格式）
4. 放入 `assets/spirecraft/` 对应目录，`runClient` 检查
